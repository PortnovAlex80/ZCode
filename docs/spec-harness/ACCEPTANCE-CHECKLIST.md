произошло. Терминология: «главное окно» — широкий центр (чат или документ в зависимости

## 1. Ролевой тоггл «Боковая панель»

Одна кнопка в шапке главного окна, рядом с кнопками окна.

- [ ] 1.1. Обычный режим (чат в центре): «Скрыть боковую панель» прячет панель вкладок
      (Open doc и др.), чат распахивается на всю ширину; кнопка меняется на
      «Показать боковую панель» и возвращает всё назад.
- [ ] 1.2. Режим «Документ в центре»: та же кнопка в том же месте теперь прячет чат,
      документ распахивается; возврат работает.
- [ ] 1.3. Спрятать боковую панель → свап → спрятать снова → вернуть свап: скрытое
      остаётся скрытым, роли меняются, ничего не ломается и не мигает.
- [ ] 1.4. Старых кнопок больше нет: ⤢ «Развернуть документ» в шапке документа и
      отдельная стрелка возврата чата исчезли — управляет только единый тоггл.

## 2. Мёртвые состояния (баг «все экраны пропали и не вернуть»)

- [ ] 2.1. Из СВАПНУТОГО режима: скрыть боковую панель (чат) → скрыть панель вкладок →
      нажать свап. После КАЖДОГО шага на экране остаётся кнопка возврата и кнопки окна.
- [ ] 2.2. То же из обычного режима и в другом порядке нажатий.
- [ ] 2.3. Итог: никакой комбинацией нельзя получить пустой экран без пути назад.
      Если получилось — запишите последовательность нажатий, это баг.

## 3. Обсуждение в плавающем окне

- [ ] 3.1. Иконка «вынести в окно» у обсуждения документа: обсуждение становится
      отдельным окном ОС, всегда поверх остальных (пин автоматический, без кнопки).
- [ ] 3.2. Перетащить окно на второй монитор; написать туда сообщение/черновик —
      сессия живая, стриминг работает.
- [ ] 3.3. Закрыть окно крестиком ОС или иконкой возврата — обсуждение возвращается
      в панель, черновик и история на месте.
- [ ] 3.4. Размер окна: изменить → закрыть → вынести снова — размер запомнился.

## 4. Чат, отцепленный от ZCode

- [ ] 4.1. Иконка «вынести в окно» на шапке чата: чат уезжает в окно ОС, таскается
      куда угодно, всегда поверх; приложение продолжает работать.
- [ ] 4.2. Общий слот: пока чат вынесен, вынести обсуждение — чат автоматически
      вернётся в приложение без потерь; и наоборот.
- [ ] 4.3. Вернуть всё на места — компоновка и состояние исходные.

## 5. Регрессия после переделок

- [ ] 5.1. Open doc: открытие документа, перевыбор другого через селектор в шапке,
      черновик каждого файла живёт свой.
- [ ] 5.2. Свап «Документ в центре»/«Чат в центре», разделитель между чатом и
      документом корректно тянется ПОСЛЕ изменения размера окна в обоих режимах.
- [ ] 5.2a. ИНВЕРСИЯ (живой баг 2026-10-14): окна поменяны местами — документ в
      центре, чат справа; управление размером по СРЕДНЕМУ разделителю (перетаскивание
      И стрелки/клавиатура) меняет размер в правильном направлении: тянешь/жмёшь
      стрелку вправо — ширина уходит той панели, что справа (чату), влево — центральной
      (документу). Проверить до и после изменения размера окна и в обоих режимах.
- [ ] 5.3. Кнопок «Move chat/panel to window», «Return to Main», «Open project in
      window» нигде нет (функционал переноса в отдельные ОС-окна удалён).
- [ ] 5.4. Иконка Z на панели задач у работающего приложения (не Electron).
- [ ] 5.5. Свёрнутость/разворот навигатора, вкладки панели, метаданные при повторном
      открытии — на месте.

## 6. Open doc: txt + поиск в выборе файлов

- [ ] 6.1. Файлы .txt проекта видны в списке документов «Open doc» и открываются в
      панели как Markdown: просмотр, редактирование черновика, сохранение.
- [ ] 6.2. Клик по строке выбора файла открывает выпадающий список со строкой поиска
      (иконка лупы): печатаете — список фильтруется сразу, без лишних кликов.
- [ ] 6.3. Клавиатура: стрелки листают, Enter открывает верхнее совпадение, Esc
      закрывает. Двойной клик по строке файла открывает его сразу.
- [ ] 6.4. Фильтр регистронезависимый, ищет по относительному пути.

## 7. Регрессия Open doc (живые баги 2026-10-14)

- [ ] 7.1. Перенос строк: длинные строки в документе (.md/.txt) переносятся по ширине
      панели и в режиме просмотра, и в режиме редактирования — горизонтального
      скролла у обычного текста нет.
- [ ] 7.2. Переключение «Редактирование ⇄ Глаз» при открытом документе не ломает
      рендеринг; панель «Обсуждения» открывается в обоих режимах и после
      многократных переключений; закрывать/переоткрывать документ для восстановления
      не требуется.
- [ ] 7.3. Выбор файла: из селектора в шапке панели и через «+ → Open doc» открывается
      выбранный документ (не застревает на первом открытом); селектор показывает
      текущий файл; черновик каждого файла свой.

## 8. Кнопка «+» — новые вкладки документов

- [ ] 8.1. Клик «+» добавляет НОВУЮ вкладку документа рядом с существующими (не молчит при уже открытом документе).
- [ ] 8.2. Заголовок вкладки отражает открытый документ; черновик каждого пути живёт свой; закрытие одной вкладки не закрывает остальные.


## 9. Пути в пикере документов

- [ ] 9.1. В списке/поиске пикера — чистые пути относительно проекта: имя файла главное, папка второстепенно, прямые слэши, без «./» и абсолютных префиксов.
- [ ] 9.2. Поиск ищет ровно по тому, что показано на экране.
