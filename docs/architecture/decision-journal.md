## 2026-10-18 — Persistent conversation windows

User requested concurrent conversations across projects and restoration of their
native placement and documents. Classified complicated. Three independent option
investigations and a separate challenge rejected cloning the complete workbench
(shared global pane IDs/stores) and reopening the independent-renderer protocol.
Selected retained addressed leaves with existing scoped providers and native
portals. Main owns geometry; UI owns desired-open descriptors; existing Host owns
history and execution. Record: [ADR 004](decisions/004-persistent-conversation-windows.md).
Key review requirements: one composer, no current-project callback leakage,
stable placement after Return, close versus Quit separation and actual-window
keyboard focus. Acceptance evidence belongs to the implementation checklist.
