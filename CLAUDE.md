# Repository instructions

Before working in this repository, read and follow [AGENTS.md](AGENTS.md),
including its Git workflow and completion rules, and any applicable nested
AGENTS.md files.

[docs/git/workflow.md](docs/git/workflow.md) is the shared Git policy for every
agent. Work in the existing `dev` checkout by default, commit completed and
verified changes, and do not automatically create branches or worktrees.

Keep detailed rules in AGENTS.md and the shared workflow rather than maintaining
a separate, potentially conflicting policy here.
