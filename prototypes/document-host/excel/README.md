# Excel: статус возможностей адаптера

Источник требования: [DOCUMENT-HOSTS.md:76](../../../docs/spec-harness/DOCUMENT-HOSTS.md) и R-11 [чек-листа](../../../docs/spec-harness/IMPLEMENTATION-CHECKLIST.md). Страница отражает дерево после волны 3 и обновляется с каждой принятой волной. Установка и подключение: [общая инструкция](../README.md). Адаптер Excel живёт в [office-adapter.js](../office-adapter.js); контракты и ограничения: [SRS](../../../docs/spec-harness/DOCUMENT-HOSTS.md).

Статусы: `native-fixture-verified` — проверено на реальном API Excel через собственные одноразовые fixture-документы; `UI-fixture-only` — проверено только юнит/UI-фикстурами с заглушками; `live-gated open` — приёмка требует живого ZCODE/модели/GUI и пока закрыта; `not implemented` — не реализовано. Ничто из `live-gated open` не считается проверенным.
